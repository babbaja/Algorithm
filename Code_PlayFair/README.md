# Playfair 암호

## 풀이 메모

입력 문자열을 두 글자씩 묶은 뒤, 만들어진 문자 쌍의 위치 관계에 따라 암호화했다.

### 헷갈렸던 부분

같은 문자로 이루어진 쌍을 나누는 규칙과 마지막 한 글자를 채우는 규칙은 서로 다르다.

- 한 쌍의 두 문자가 같으면 중간에 `X`를 넣는다.
- 같은 문자가 `X`라면 중간에 `Q`를 넣는다.
- 문자열의 마지막에 한 글자만 남으면, 그 글자가 `X`여도 항상 `X`를 붙인다.

처음에는 마지막 남은 글자가 `X`이면 `Q`를 붙이는 것으로 구현했지만, 마지막 글자에 대한 패딩은 예외 없이 `X`를 사용해야 했다.
