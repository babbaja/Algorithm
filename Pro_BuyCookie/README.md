# 프로그래머스 - 쿠키 구입

## 풀이 메모

두 아들이 가져갈 쿠키의 경계를 `i`와 `i + 1` 사이로 정하고, 각 경계마다 왼쪽과 오른쪽 구간의 합을 비교했다.

```java
int l = i;
int r = i + 1;
```

`l`과 `r`을 따로 두고 반복문을 돌면서 `i`를 기준으로 양옆으로 뻗어나간다.

- 왼쪽 합이 오른쪽 합보다 작으면 `l`을 왼쪽으로 이동한다.
- 오른쪽 합이 왼쪽 합보다 작거나 같으면 `r`을 오른쪽으로 이동한다.
- 두 구간의 합이 같아질 때마다 현재 합으로 최대값을 갱신한다.
- 더 이상 확장할 수 없으면 다음 경계를 확인한다.

```java
if (lsum == rsum) {
    answer = Math.max(answer, lsum);
}
```

쿠키 개수가 모두 양수이기 때문에 합이 더 작은 쪽을 확장하는 방식으로 탐색할 수 있다.
